# E2E Project

A test project of the PM bot's end-to-end test (tests/e2e in the hermes-bot repository). Its tickets
are requests the bot handed over. There is no code to change.

Work the ticket in its state. When a requirement is unclear, ask the requester: publish a comment
that starts with `# Question`, add the label `Question` and freeze the ticket. When the work is
done, publish a `summary` comment and move the ticket to `review`.
